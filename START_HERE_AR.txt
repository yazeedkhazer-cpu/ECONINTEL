ECONINTEL v1.2 — تحديث البيانات الرسمية عبر الإنترنت

هاي نسخة مطوّرة من v1.1 وليست مشروعًا جديدًا.

جاهز بالكود:
1) جلب BLS آليًا من دون مفتاح (حتى 22 مؤشرًا بما في ذلك المحسوب منها).
2) جلب FRED بالمفتاح المجاني لثمانية مؤشرات إضافية.
3) تحديث واجهة الموقع من ملف JSON منشور كل 5 دقائق، مع زر التحقق.
4) تشغيل تحديثات البيانات ساعة بساعة وقت الإصدارات الاقتصادية في أيام العمل عبر GitHub Actions.
5) سجل تاريخ كل مؤشر، مصدره، ووقت سحب بياناته، وتنبيه عند وجود بيانات قديمة.

مهم: الموقع لم يُنشَر بعد، ولم يتم تنزيل بيانات حقيقية داخل هذه الحزمة؛ الأرقام الموجودة هي لقطة مرجعية v1.1 حتى يتم تشغيل الموصّلات على GitHub.
4 مؤشرات ما تزال مراجع: ADP، ISM الصناعة، ISM الخدمات، وDiffusion.

خطوة النشر: أنشئ مستودع GitHub جديدًا باسم econintel، وارفع محتويات مجلد us-economic-intelligence، ثم:
Settings > Pages > Source > GitHub Actions
Settings > Secrets and variables > Actions > New repository secret > FRED_API_KEY
Actions > Update ECONINTEL and publish website > Run workflow

اقرأ README.md للتفاصيل والأوامر ومصادر البيانات.
